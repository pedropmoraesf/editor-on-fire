### Status / testing

**Experimental community build** — not an official or stable EOF release.

Build completed successfully on Windows and the executable remained running during a six-second smoke test. Two source tests passed (DTX XML save wiring and PSARC album artwork). A FluidSynth integration test was not possible without a GM SoundFont; the PSARC effects workflow test did not pass. Full workflow and regression tests have **not** been completed. Keep backups of your EOF projects.
